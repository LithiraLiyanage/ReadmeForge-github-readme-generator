## 🚀 Overview

**ReadmeForge** helps developers create professional GitHub README files without manually writing markdown from scratch.

Users can fill a step-based form, select tech stacks, add features, commands, environment variables, API endpoints, folder structure, author links, and instantly generate a polished README with animations, badges, preview image, architecture, setup guide, CV bullet, and interview explanation.

---

## ✨ Key Features

- 🔐 JWT authentication and protected routes
- 🌿 Green SaaS dashboard UI
- 🧙 Step-based README generator wizard
- 🏷️ Badge generator for 30+ technologies
- 👀 Live markdown preview
- 📋 Copy markdown button
- ⬇️ Download README.md button
- 💾 Save generated README history
- ⭐ Favorite README documents
- 🔁 Duplicate previous README
- ✏️ Edit saved README data
- 🗑️ Delete saved README
- 🔎 Search/filter saved READMEs
- 📊 Dashboard analytics
- ✅ Strong frontend/backend validations
- 🛡️ Role-based admin protection

## ⚙️ Run Locally

```bash
docker compose up -d mongo
```

```bash
cd backend
npm install
copy .env.example .env
npm run dev
```

```bash
cd frontend
npm install
copy .env.example .env
npm run dev
```

Frontend: `http://localhost:5173`  
Backend: `http://localhost:5000`
